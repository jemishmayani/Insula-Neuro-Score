# Insula Neuro Score v0.11.0: Scores & Grades

> **Not clinically ready.** For review and testing only. See the medical content audit.

## Install
- Download `InsulaNeuroScore-v0.11.0.apk` below. Android 7.0 or later.
- Installs as an update over v0.10.0 (same signing key). Versions before 0.10.0 must be uninstalled first.

## What's new
- **Item types:** every item is labelled Score, Grade, Classification or Measurement. MRC power, House-Brackmann and other grades are no longer presented as scores.
- **Quick groups** on Home and at the top of Calculate and Guide:
  - Quick Clinical Examination: GCS, MRC power, House-Brackmann, reflex grade, Modified Ashworth
  - Neurotrauma: GCS, GCS-P, Marshall, Rotterdam, ISS
  - Vascular: Hunt & Hess, WFNS, Modified Fisher, Spetzler-Martin, Borden, Cognard
- **Cleaner calculators and guides:** optional details (side, muscle, reflex, joint, follow-up) are grouped separately and never change the result. Guides label grades and classes correctly and show ranges as clinicians read them.

## Fixed
- RASS is consistently withheld for licensing: no JSON ships and it has no links in the app. The audit and the source agree.
